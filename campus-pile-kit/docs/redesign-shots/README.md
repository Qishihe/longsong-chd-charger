## 一、🔴 先看这个：正式版现在有个 P0，跟你的样张无关但**同一天修**

我从线上正式版 v2.03 解密了云端清单（`scratch/cloud_dump.mjs`，口令走 `SYNC_PWD` 环境变量）：

- 云端 **109 条** = 仓库 97 + 物流 12
- 那 12 条的 `location` 是 `渭水‑物流服务中心`，中间是 **U+2011 不换行连字符**
- 而 `map-data.js` 的 areas 键和 `DEFAULT_DEVICES` 用的是**普通 `-`（U+002D）**

线上实测（`scratch/verify_61dash.mjs`，注入真实 109 条 + schema=3）：

```
areas[location] 命中? false
mapAreaOf 判成       「渭水-朝晖体育场南」
amapDevices()        { 朝晖 48, 北门 37, 20号楼 24 }   ← 物流 0 台
```

朝晖弧只有 36 个弧位，48 台挤 → **12 台被 `filter(pos)` 静默丢掉**。

**你为什么没踩到**：`preview.html` 的 `DEVICE_SCHEMA` 被你升到 4，迁移分支里
`location: meta.location || d.location` 会用 `DEFAULT_DEVICES` 的值覆写 → 连字符被顺手改回 U+002D。
正式版 schema 还是 3、`DEFAULT_DEVICES` 里也没这 12 条 → **躲不掉**。
**结论：这是偶然躲过，不是设计。** 「内测正常」不等于「正式版正常」。

**修法建议**：加 `normKey()` 把 U+2011/2013/2014/2212 收成 U+002D，
在 `mapAreaOf()` 和 `appendNewLocationDevices()` **两处判据上**都过一遍。
**不要在数据文件里手改** —— 云端那批数据已经躺在产品方所有设备上了，改仓库没用。

## 三、样张本身：三个你没提的问题（都程序化验过，非肉眼）

### ① 底图横向被拉伸 19%

```js
const s = Math.min((VW-PAD*2)/(maxx-minx), (VH-PAD*2)/(maxy-miny));
// X 和 Y 共用同一个 s
```

西安地区 1° 经度 ≈ 92.9 km、1° 纬度 ≈ 111 km（纬度方向每度更长）。
经纬跨度换算：经 0.024811° = **2305 m**，纬 0.012486° = **1385 m**，
**真实宽高比 = 1.66**，等比缩放后画出来是 **1.99** → 横向胖了 19%。

按理该用两个系数：`sx = 26924`、`sy = 35079`（差 30%）。
样张是「方位示意」，1.66→1.99 的失真也许可接受，但**说明要改**；
若后面要在这底图上标真实桩位，**必须先修**（`map-amap.js` 走高德底图，不受这个影响）。

### ② 两个地点圆标必然重叠

圆标位置取 `D.areas[loc].line` 的**中点**，投影后：

| 分区 | 圆标坐标 | |
|---|---|---|
| 渭水-20号楼 | (117.0, 304.1) | — |
| 渭水-物流服务中心 | (183.6, 237.1) | — |
| **渭水-北门** | **(596.0, 80.4)** | ← |
| **渭水-朝晖体育场南** | **(590.4, 127.2)** | ← |

北门与朝晖**只相距 47px**，而圆标 `r=15` + `halo r=25` → 必然叠在一起。
①图里能看到的就是这个：右上角两个圆标糊成一团，选中项往上浮 46px 的白底标签
又正好压在右侧的缩放控件下面。

**成因**：`areas[北门].line` / `areas[朝晖].line` 是很短的示意线段，其中点并不代表地点重心。
**建议**：这几个非线段型分区改用写死的经纬度（或用 `D.labelPts`），别拿 `line` 中点当位置。
物流服务中心倒是适合用 `line` 中点 —— 它本来就是线段型。

### ③ 文案：桩位数写成了插座数

②图里：「北门 · 37 台设备 · **148 个桩位** · 观测到 144 个插座」——
**148 是插座数**（37×4），桩位应该是 **37**。20号楼那行同理写的是「96 个桩位」，应为 24。

另外「**实时 · 17:52:13**」这个时间戳也是编的（数据是假的）。
建议样张阶段把「实时」改成「样例数据」，免得截图流出去被当真。

### ④ 少一个地点

样张只有 3 处，**云端已经有第 4 处**（物流服务中心）。
搬进真实版时这处会漏，`PLACES` 要跟着 `SCHEMA_ADDED_LOCATIONS` 走，别写死。
