## 四、🔴 纯静态路线**必须知道**的三件事

**① 数据只在本机 —— 清缓存 / 换手机就没了** ✗
所有数据在浏览器 `localStorage`（键前缀 `cpk.`）里 ✓ 所以：**部署完第一件事就是导出备份**（见第五节），
并且**把备份文件存到别处**（网盘/邮箱）✓

**② 每台设备要各自粘一次凭证** ✗
原来的"一个人抓一次、所有人能用"（凭证共享）依赖平台云 ✓ 纯静态没有 ✓ 日常使用不影响，只是新手机要重粘 ✓

**③ 加设备要改代码** ✗
设备清单云同步失效，用页面内置的默认清单 ✓ 要加桩位就得编辑 `index.html` 里的 `DEFAULT_DEVICES` ✓
⚠️ **注意**：正式版 `index.html` 内置 **97 台**，**不含物流 W-01~W-12** ✗
（内测版 `preview.html` 是 109 台，但它带"测试预览版"横幅，不适合正式部署）
→ **要那 12 台的话，得把它们补进 `index.html`**（另开一轮做，不难）

**失效的还有**：历史快照趋势图（没有服务端采集）· 凭证自动换 token（那需要微信小程序的 `wx.login()`，**任何自建方案都做不到**）✗

## 五、数据导出 / 导入（复制粘贴即可）

**从旧站导出**（在 `chd-charge.app.workbuddy.host` 上，F12 → Console）：

```js
(() => {
  const out = {};
  for (let i = 0; i < localStorage.length; i++) {
    const k = localStorage.key(i);
    if (k.startsWith('cpk.')) out[k] = localStorage.getItem(k);
  }
  const blob = new Blob([JSON.stringify(out, null, 1)], { type: 'application/json' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'chd-charge-backup-' + new Date().toISOString().slice(0, 10) + '.json';
  a.click();
  console.log('已导出', Object.keys(out).length, '项');
})()
```

**导入新站**（新域名上，F12 → Console）：

```js
window.__pick = () => new Promise(r => {
  const i = document.createElement('input'); i.type = 'file'; i.accept = '.json';
  i.onchange = async () => r(JSON.parse(await i.files[0].text()));
  i.click();
});
const data = await window.__pick();
Object.entries(data).forEach(([k, v]) => localStorage.setItem(k, v));
location.reload();
```

⚠️ **导出的文件含你的登录凭证，别公开发** ✗
只带设备清单（可安全分享）：`copy(localStorage.getItem('cpk.devices'))` ✓

## 七、⚠️ 那份 `DEPLOY-GUIDE.md` 里两处**被实测证伪**（请以本文为准）

| 指南的说法 | 实测 |
|---|---|
| 「`http://127.0.0.1` ❌ 不加载高德，`window.AMap === undefined`」 | ❌ **不符** —— 实测能加载（`AMap=object`、瓦片 200、无 `INVALID_USER_DOMAIN`）✓ |
| 第六节"必须留着的最小集合" | ❌ **漏了 `manifest.webmanifest`**；且**多算**了 `map-beimen.svg`、`map-weishui-raw.webp` |

**为什么"漏 `manifest.webmanifest`"比看起来严重**：

```js
cache.addAll(SHELL)   // 只要有 1 条 404，整个预缓存 reject
  .catch(() => self.skipWaiting())   // ← 而 sw.js 把这个失败「吞掉」了
```

→ **整个离线壳静默失效**（`index.html` / 图标都不进 cache）→ **断网首开白屏** ✗
这是最难查的那类"静默失败" ✓ 所以它**必须在** ✓

**另外**（指南没提）：`serve_gzip.py` 的 docstring 数字是旧的 —— 实测可压缩文本
**1,268,955 B → 433,513 B（2.93x）**，载入 **31 个文件**（docstring 写 476→157 KB、16 个文件）✓

## 八、关于 `map-key.local.js`（提醒，不是拦你）

它里面是**真实高德 Key + 安全密钥的明文** ✓ 产品方已选择"打包带上真实 Key"（省事优先）✓

但要知道两件事：
1. **线上那份现在是公开可取的**（`https://chd-charge.app.workbuddy.host/map-key.local.js` → 200）✗
2. 你新部署后，它**同样会公开可取** ✓ 所以：
   - **轮换 Key** 是值得的 ✓ 轮换后记得**把新域名加进白名单**
   - **别把它提交进公开仓库** ✗
   - 高德 Key 的安全模型本来就靠**域名白名单**兜底，所以配好白名单比藏文件更有效 ✓
